# SfSplitterPanel 分割面板组件

## 简介

基于 Element Plus 的 `ElSplitterPanel` 组件封装。通常配合 `SfSplitter` 使用。

## 基础用法

```html
<SfSplitter>
  <SfSplitterPanel>Left</SfSplitterPanel>
  <SfSplitterPanel>Right</SfSplitterPanel>
</SfSplitter>
```

## API 参考

### Props (属性)

继承所有 `ElSplitterPanel` 的属性。

### Slots (插槽)

继承所有 `ElSplitterPanel` 的插槽。

### Exposed (暴露)

透传 `ElSplitterPanel` 的所有方法和属性。
