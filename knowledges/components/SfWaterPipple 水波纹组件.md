# SfWaterPipple 水波纹组件

## 简介

用于展示水波纹动画效果的组件，通常用于加载进度或状态展示。

## 基础用法

```html
<SfWaterPipple :width="100" :height="100" :percentage="50" />
```

## API 参考

### Props (属性)

| 属性名     | 类型     | 默认值 | 说明                   |
| ---------- | -------- | ------ | ---------------------- |
| width      | `Number` | `100`  | 容器宽度 (px)          |
| height     | `Number` | `100`  | 容器高度 (px)          |
| percentage | `Number` | `20`   | 波纹覆盖百分比 (0-100) |

### Slots (插槽)

| 插槽名  | 说明                         | 作用域参数 |
| ------- | ---------------------------- | ---------- |
| default | 中心内容，默认显示百分比数字 | -          |
