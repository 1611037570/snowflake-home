# SfSplitter 分割器组件

## 简介

基于 Element Plus 的 `ElSplitter` 组件封装，用于构建可拖拽调整大小的布局。

## 基础用法

```html
<SfSplitter layout="vertical">
  <SfSplitterPanel>Top</SfSplitterPanel>
  <SfSplitterPanel>Bottom</SfSplitterPanel>
</SfSplitter>
```

## API 参考

### Props (属性)

继承所有 `ElSplitter` 的属性。

### Slots (插槽)

继承所有 `ElSplitter` 的插槽。

### Exposed (暴露)

透传 `ElSplitter` 的所有方法和属性。
