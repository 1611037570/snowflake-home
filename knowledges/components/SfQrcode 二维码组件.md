# SfQrcode 二维码组件

## 简介

用于生成二维码的组件，支持动态更新内容和尺寸。基于 `qrcode` 库实现。

## 基础用法

```html
<SfQrcode value="https://example.com" :size="200" />
```

## API 参考

### Props (属性)

| 属性名 | 类型     | 默认值 | 说明            |
| ------ | -------- | ------ | --------------- |
| value  | `String` | `''`   | 二维码内容      |
| size   | `Number` | `256`  | 二维码尺寸 (px) |

### 功能说明

- **动态生成**：监听 `value` 和 `size` 变化自动重新生成。
- **高容错率**：默认使用 'H' (High) 容错级别。
