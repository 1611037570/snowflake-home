# SfTheme 主题切换组件

## 简介

提供明亮/暗黑/跟随系统三种模式切换的组件。包含一个图标按钮和下拉菜单，支持实时预览和持久化存储。

## 基础用法

```html
<!-- 放置在导航栏或设置面板中 -->
<SfTheme />
```

## API 参考

### Props (属性)

无

### 功能说明

- **模式切换**：支持 `light` (明亮)、`dark` (暗黑)、`system` (跟随系统) 三种模式。
- **状态管理**：通过 `useThemeStore` 管理主题状态。
- **图标交互**：根据当前主题显示不同的图标（太阳/月亮），且图标带有点击交互和悬停下拉菜单。
