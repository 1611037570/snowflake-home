# 雪花起始页——本地化浏览器起始页

[简体中文](README.md) | [English](README.en.md)

## 📌 项目介绍

项目主体为雪花起始页，基于起始页衍生拓展了多个小工具；同时集成了多项基建功能。
通过本项目，您可以学习 **Vue3**、**TypeScript**、**Vite** 等现代前端技术的实战应用。
项目于2020年9月3日上线，2025年11月22日开始重构并开源。

## 🎯 核心产品模块

- ✨ **雪花起始页**：项目核心载体，提供个性化自定义的网站起始页 （http://nannan.work）
- 📄 **简历生成器**：可视化简历编辑工具，支持模板选择、内容自定义、一键导出 （http://nannan.work/#/resume）
- 🛣️ **图片处理工具**：轻量级图片套件，涵盖压缩、裁剪、格式转换等常用功能 （http://nannan.work/#/image）
- 👤 **个人主页**：作者个人展示页面 （http://nannan.work/#/index）

## 🔧 核心基建功能

- 🎮 **命令工具**：基于 **Node.js** 实现交互式命令菜单；支持上下箭头键导航、回车键快速执行
- 📋 **表单系统**：基于 **ElementPlus** 实现动态表单组件；支持对象/数组类型字段、配置驱动、数据双向绑定
- 📥 **缓存管理**：基于 Pinia 实现 LFU-R 策略缓存管理器；支持自定义过期配置、过期/超限自动淘汰
- 🚀 **请求管理**：基于 **Axios** 实现请求类；支持多实例、自定义拦截器、统一请求/响应处理机制
- 🛣️ **路由管理**：基于 **VueRouter** 实现自动注册；支持动态生成、视图懒加载及错误页面重定向机制
- 🎨 **样式管理**：基于 **TailwindCSS** 主题化 CSS 颜色变量体系；支持白天/夜间模式切换
- 🌐 **语言管理**：基于 **i18n** 实现路由级多语言支持；支持中文/英文切换、可扩展
- 🧩 **组件库**：基于 **ElementPlus** 实现专属项目的风格组件库；支持按需/全局导入
- 🛠️ **工具库**：基于 **VueUse** 实现专属项目的风格工具库

## 🚀 安装与运行

推荐使用 **VS Code** 或 **Trae** 作为开发环境，项目提供了 `.vscode` 配置文件，能够带来更好的开发体验。

```bash
# 安装依赖
pnpm install

# 开发环境运行
pnpm dev

# 构建生产版本
pnpm build
```
