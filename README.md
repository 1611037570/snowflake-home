# 雪花起始页——浏览器起始页、多工具

[简体中文](README.md) | [English](README.en.md)

## 📌 项目背景

项目于2020年9月3日上线，2025年于11月22日开源。
项目主体为雪花起始页，衍生拓展了个人主页、简历生成器、图片处理工具等多个小工具；
同时集成了多语言、持久化、主题切换、响应式设计等基建功能。
通过本项目，可以你学习到通过Vue3、TypeScript、Vite等现代前端技术开发项目。

## 🚀 安装与运行

推荐使用vscode或trae作为开发环境，项目提供了.vscode的配置文件，能够带来更好的开发体验。

```bash
# 安装依赖
pnpm install

# 开发环境运行
pnpm dev

# 构建生产版本
pnpm build
```
