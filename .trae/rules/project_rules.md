# 项目开发规范

## 🌐 语言与工具

1. 全程使用中文进行代码注释和文档编写
2. 项目依赖管理统一使用 pnpm
3. 开发优先使用 vueuse 提供的工具函数

## 📝 代码风格

1. 新增代码时编写简约、清晰的注释
2. 导入和函数的注释统一放在代码上方
3. 参数注释放在参数右侧
4. 遵循最小化代码原则，不添加额外功能

## 🎨 Vue 开发规范

1. Vue 文件的 script 部分必须使用 setup 语法糖
2. Vue 文件的样式必须使用 Tailwind CSS 写法
3. Vue 文件的 template 避免多重 div 嵌套
4. 使用自定义 Snowflake 主题色类名，参考知识库开发文档中的主题色彩章节

## 🧩 组件规范

1. 优先使用 `./src/components/` 目录下的自定义组件
2. 组件导入和使用时，必须使用大驼峰命名法
3. ElementPlus 组件已全局挂载，直接使用无需导入

## 🎯 图标规范

1. 图标名称必须使用 @iconify/vue 图标库
2. 图标渲染统一使用 SfIcon 组件，该组件已全局挂载，无需导入
