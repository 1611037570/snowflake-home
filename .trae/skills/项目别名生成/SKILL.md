description: '从根目录开始，深度遍历项目所有文件和文件夹，确保根目录文件 100% 覆盖。通过扫描符合规则的文件，生成文件路径与中文别名的 JSON 映射；严格遵循 .gitignore，忽略项不深度遍历。适用于项目别名维护和目录梳理。'
---

执行规则

1.  **多维解析忽略规则**：
    - 读取项目根目录 `.gitignore`。
    - 结合 `.trae/.ignore`（如果存在）。
    - 核心：忽略项（如 `node_modules/`, `dist/`, `.git/`）仅保留名称作为 JSON 键，其值固定为说明字符串，**绝对不进行深度遍历、不展开子项**。

2.  **强制全量扫描根目录**：
    - **第一步**：必须调用工具列出根目录下**所有**文件和文件夹，不得遗漏任何一个非忽略项。
    - **检查清单**：特别关注配置文件（如 `vite.config.ts`, `tsconfig.json`, `package.json`, `.env` 等）。
    - **过滤**：排除被 `.gitignore` 匹配的项。

3.  **分层递归遍历策略**：
    - **根目录文件**：逐一生成中文别名。
    - **组件核心目录 (`src\components`)**：深度递归遍历 3 层，确保当前目录下文件都有别名。
    - **业务逻辑目录 (`src`)**：深度递归遍历 2 层，确保当前目录下文件都有别名。
    - **其他顶层文件夹**：深度递归遍历 1 层，确保当前目录下文件都有别名。

4.  **生成精准中文别名**：
    - 遵循“简洁、专业、见名知意”原则。
    - 根据文件名后缀、所在目录、文件内容关键字（如 `config`, `service`, `hook`, `view`）推断用途。

5.  **结构化输出与保存**：
    - 生成与实际目录层级 100% 一致的 JSON。
    - 键：文件/文件夹原名。
    - 值：文件对应中文别名；文件夹对应嵌套对象（包含其内部所有符合规则的子项）。
    - **最终动作**：将 JSON 写入 `knowledges/项目别名.json`，覆盖旧内容。

输出结构示例

{
"node_modules": "Node.js 依赖模块目录",
"src": {
"main.ts": "项目全局初始化入口",
"App.vue": "Vue 根组件",
"components": {
"BaseButton.vue": "基础按钮组件"
}
},
"vite.config.ts": "Vite 构建配置文件",
"tsconfig.json": "TypeScript 编译配置主文件",
"package.json": "项目元数据与依赖配置文件"
}

重点强调：

1. **根目录严禁遗漏**：必须包含 `vite.config.ts`, `tsconfig.json` 等所有顶级配置文件。
2. **深度与精度并存**：核心代码区深度挖掘，资源区精准命名。
3. **性能优化**：对忽略目录（如 `node_modules`）执行“见名止步”，不进行任何递归操作。
