# 简历智能体包说明

本目录集中维护简历范围内的全部 AI 能力。编辑器、导入页面和助手只负责收集输入、选择能力并展示结果。

本包与 `packages/ai` 同级；`packages/ai` 提供基础模型能力，本包提供简历场景的提示词、技能、任务、工具和数据契约。

目录职责：

- `request/`：模型选择、协议适配、流式响应、取消、重试和工具循环入口。
- `tasks/`：正文处理、简历导入、普通会话、面试回答及每轮助手任务理解。
- `prompts/`：助手反思和其他跨入口共用提示词。
- `skills/`：简历、行业和面试技能正文。
- `schema/`：从简历表单配置生成供 AI 使用的模块与字段契约。
- `tools/`：简历读取、写入、语言切换、技能加载和写入校验。
- `context/`：本轮简历读取范围、脱敏和媒体裁剪。
- `reports/`：AI 评分报告解析与结构校验。
- `format/`：模型富文本输出的清洗、归一化与安全标签配置。
- `writingRules.ts`：所有简历正文生成与改写共用的写作规则。
- `index.ts`：提供给其他模块的统一公开出口。

依赖约定：

- 本目录不得依赖 `resume/assistant`。
- 页面和助手不得直接调用模型实例的 `request` 或 `react`，统一经过本目录。
- AI 字段契约读取简历表单配置，但不在 AI 目录重复声明业务字段。
- 任务技能正文属于 AI 能力；技能选择、功能入口和交互流程属于助手路由。
