# 组件文档生成器

本技能用于自动分析 Vue 组件，并生成标准化的 Markdown 技术文档。

## 任务目标

扫描 `src/components` 目录下的组件文件，分析其 `props`、`events`、`slots` 以及用法，并在 `knowledges/components` 目录下生成对应的文档文件。

## 执行步骤

1.  **遍历组件目录**
    - 递归扫描 `src/components` 下的所有子目录（包括 `base`, `business`, `el` 等嵌套目录）。
    - 识别每个包含 `.vue` 文件的组件文件夹。
    - 如果用户未指定特定组件，则**必须处理所有扫描到的组件**，不得仅处理第一个。

2.  **批量分析组件**
    - 对每一个识别到的组件文件夹（例如 `src/components/base/icon`）：
      - **定位主文件**：寻找与文件夹同名的 `.vue` 文件（例如 `icon.vue`）。
      - **解析代码**：读取该主文件，提取关键信息：
      - **组件名称**：组件的英文名称（如 `SfButton`）和中文名称（如 `按钮`，通常在文件顶部注释中）。
      - **组件描述**：从文件顶部的注释或功能推断。
      - **Props**：属性名称、类型、默认值、必填项、描述。
      - **Events**：事件名称、参数、触发时机。
      - **Slots**：插槽名称、作用域参数、用途。
      - **Exposed**：对外暴露的方法或属性（如果有）。

3.  **生成文档内容**
    - 文档模板结构：

      ````markdown
      # [组件名称]

      ## 简介

      [简要描述组件的功能和用途]

      ## 基础用法

      ```html
      <[组件名] ... />
      ```
      ````

      ## API 参考

      ### Props (属性)

      | 属性名 | 类型 | 默认值 | 说明 |
      | ------ | ---- | ------ | ---- |
      | ...    | ...  | ...    | ...  |

      ### Events (事件)

      | 事件名 | 参数 | 说明 |
      | ------ | ---- | ---- |
      | ...    | ...  | ...  |

      ### Slots (插槽)

      | 插槽名 | 说明 | 作用域参数 |
      | ------ | ---- | ---------- |
      | ...    | ...  | ...        |

      ```

      ```

4.  **保存文档**
    - 将生成的文档保存至 `knowledges/components` 目录。
    - 文件名格式：`[组件名] [中文名称]组件.md`（例如 `SfButton 按钮组件.md`）。

## 最佳实践

- 生成文档前，先检查组件是否有现有的注释，优先使用现有注释作为描述。
- 对于复杂的组件，尝试给出一个完整的示例代码。
- 保持文档格式的一致性。
