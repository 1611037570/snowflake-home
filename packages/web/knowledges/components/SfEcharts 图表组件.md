# SfEcharts 图表组件

## 简介

基于 ECharts 封装的通用图表组件，内置了深度合并配置、自动缩放和主题适配功能。

## 基础用法

```html
<SfEcharts :options="chartOption" />
```

## API 参考

### Props (属性)

| 属性名  | 类型     | 默认值 | 说明                                 |
| ------- | -------- | ------ | ------------------------------------ |
| options | `Object` | `{}`   | ECharts 配置项，会自动与默认配置合并 |

### 功能说明

- **默认配置**：内置了通用的 grid、legend、tooltip 等默认配置，简化使用。
- **深度合并**：传入的 options 会与默认配置深度合并。
- **主题适配**：(需确认 `useEcharts` 内部实现) 通常会处理响应式大小调整。
