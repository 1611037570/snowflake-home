# SfCollapse 折叠面板组件

## 简介

基于 Element Plus 的 `ElCollapse` 组件封装。

## 基础用法

```html
<SfCollapse v-model="activeNames">
  <ElCollapseItem title="标题" name="1"> 内容 </ElCollapseItem>
</SfCollapse>
```

## API 参考

### Props (属性)

继承所有 `ElCollapse` 的属性。

### Slots (插槽)

继承所有 `ElCollapse` 的插槽。

### Exposed (暴露)

透传 `ElCollapse` 的所有方法和属性。
