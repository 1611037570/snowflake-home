# SfLocale 语言切换组件

## 简介

提供多语言切换功能的下拉菜单组件。支持动态加载语言包，并自动更新当前路由的语言设置。

## 基础用法

```html
<!-- 基础用法 -->
<SfLocale />
```

## API 参考

### Props (属性)

无

### 依赖注入 (Inject)

| 注入名 | 类型     | 默认值           | 说明         |
| ------ | -------- | ---------------- | ------------ |
| color  | `string` | `'text-sf-base'` | 图标颜色类名 |

### 功能说明

- 组件会自动读取 `LANG_LIST` 常量生成语言列表。
- 切换语言时会调用 `loadPageLang` 异步加载对应的语言资源。
- 图标样式会根据注入的 `color` 变量进行调整。
