# 面试智能体

本包通过 `@snowflake/agent` 创建独立面试智能体，不依赖 `@snowflake/resume-agent`，不加载简历任务规划、写入工具、字段补齐规则或简历完成校验。

- `tasks.ts`：执行本轮请求、只读工具和内容校验。
- `prompts.ts`：统一事实边界与动作目标，只注入当前动作需要的规则。
- `skills/`：五类面试按出题、复盘、准备动作分别维护规则，不携带简历规划器的技能元数据；提示与参考回答不加载这些规则。
- `flow.ts`：轮次、阶段、固定开场与未作答结束说明。
- `types.ts`：面试配置与真实问答输入，只通过公共只读快照接收简历内容。
- `model.ts`、`host.ts`：独立面试官模型接线，不回退到简历助手或其他角色。

有关联简历时，`read_interview_resume` 只读取本场固定的脱敏业务快照；无简历时不提供该工具。行业资料通过 `read_interview_guidance` 按需读取公共目录，不引用简历智能体技能注册表。

开场、计时、暂停、轮次推进和持久化由页面会话流程负责；智能体只生成本轮明确要求的内容。停止信号只中止当前面试，不影响简历智能体。
