# 面试智能体

本包通过 `@snowflake/agent` 创建独立面试智能体，不依赖 `@snowflake/resume-agent`，不加载简历任务规划、写入工具、字段补齐规则或简历完成校验。

- `tasks.ts`：执行本轮请求、只读工具和内容校验。
- `prompts.ts`：组装公共事实与表达、当前动作、类型方法和真实进度；评价规则只用于结束后的复盘，澄清只解释原题，不给答案。
- `skills/`：五类面试按出题、复盘、准备动作分别维护规则，不携带简历规划器的技能元数据；提示与参考回答不加载这些规则。

- `flow.ts`：轮次、阶段、固定开场与未作答结束说明。
- `types.ts`：面试配置与真实问答输入，只通过公共只读快照接收简历内容。
- `model.ts`、`host.ts`：独立面试官模型接线，不回退到简历助手或其他角色。

公共提示只维护角色、事实、表达与权限；候选人自述、实际作答展示的能力、通用知识和假设场景须分清，用户更正优先。行业资料只提供背景，不能把其中的简历写作方法变成面试任务。各动作独立限定职责：出题每轮只问一个具体问题，过程中不评分、不点评对错或提供标准答案；结束后复盘只评价有效正式作答，答题思路与参考回答只处理选中的回看题目；自我介绍只生成口头稿。用户求澄清时先解释原题，不将求澄清当答错。追问路径、难度和表达结构由模型结合真实回答选择；题数、阶段、计时和结束由应用控制。

表达要求集中在 `prompts.ts`，各面试类型共用：优先呈现精炼、直接、有专业依据的内容，篇幅与结构由模型结合题目复杂度和用户需要判断，不设置统一的字数、词数、句数或要点数量上限。减少空话、重复和辅助过程，保留必要概念、机制、条件与取舍；自我介绍直接结合资料和补充要求生成，不保留失效的字数与风格配置。每轮单问属于交互节奏，不限制模型的分析深度或必要解释，不在界面截断正文。

请求只提供本轮使用的设置：训练重点仅用于专项面试，综合模拟由模型结合岗位与经历安排内容。评分方式不再由用户选择，各模拟流程结束后统一评价；澄清、跳过和未覆盖项不作为能力证据。作答表现与完成进度分别说明，提前结束不按完成比例压低评分，不将未答题计零分；完整作答的行测与 HR 保留原百分制口径。有效正式回答计数与空样本结束共用 `getInterviewAnsweredTurns`，开场不算正式回答。

逐题回看与澄清只携带所选题的上下文，不发送整场历史。题意澄清和答题思路不加载资料工具；参考回答需要核对个人经历时才按需读取简历，不强制增加一次工具调用。逐题回看保留原作答、用时与复盘；更换参考回答保留正确结论，不为求不同强造另一种答案。

模拟面试有关联简历时，`read_interview_resume` 只读取本场固定的脱敏业务快照；无简历时不提供该工具。行业资料通过 `read_interview_guidance` 按需读取公共目录，不引用简历智能体技能注册表。独立自我介绍只把脱敏简历或背景直接交给模型生成一段口头稿，不装配资料工具与面试流程规则。

开场、计时、暂停、轮次推进和持久化由页面会话流程负责；智能体只生成本轮明确要求的内容。停止信号只中止当前面试，不影响简历智能体。
