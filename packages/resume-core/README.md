# 简历公共数据

本包维护简历数据契约、媒体字段、富文本格式、脱敏与只读业务快照，不依赖任何智能体、Vue、Store 或编辑器组件。

- `schema/`：宿主注册的模块、字段和实际数据路径。
- `privacy.ts`、`mediaFields.ts`：简历与导出共用的脱敏和媒体处理。
- `snapshot.ts`：在独立副本上生成脱敏业务快照，不携带编辑状态与媒体。
- `knowledge/`：两个智能体可按需读取的行业资料，不包含业务任务或评分规则。
- `host.ts`：公共字段契约与媒体声明的注册入口，应用启动时独立于智能体注册。

宿主负责选择简历和提供数据；面试只消费快照。业务数据变更与写入校验继续由简历智能体负责。
