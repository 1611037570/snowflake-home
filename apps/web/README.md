# @snowflake/web

基于 Vue 3 + Vite 的前端应用。

## 初始入口与产品页面信息

- 环境配置中的 `VITE_DEFAULT_ROUTE`（初始入口路由）设为 `/resume` 时使用轻舟简历，设为 `/home` 时使用雪花起始页；修改后重启开发服务或重新构建。已有的默认路由偏好仍按原逻辑读取。
- `site.config.ts` 统一声明两种产品的信息：`route`（产品入口路径）、`locales`（各语言配置）、`title`（标签标题）、`description`（页面描述）、`keywords`（检索关键词）、`favicon`（网站图标地址）。两种产品目前沿用已有图标资源，地址可分别配置。
- 初始 HTML 按配置入口与默认语言注入页面信息；客户端导航完成后按实际产品路由更新，简历子路由继承简历产品信息，语言切换同步更新网页语言与页面信息。其他页面保留已有页面标题，默认描述及图标继承配置入口的产品。
- 页面信息统一由客户端入口订阅路由与语言，不再由语言包加载函数写标题；初始 HTML 是构建入口的默认信息，不代表不同直达路由各自生成了静态 HTML。
- 验证：两种入口与两种语言的 HTML 模板注入、产品路由往返与语言切换、简历子路由继承、其他页面标题保留、路径边界及无重复标签核验通过；生产构建与差异格式检查通过，实际浏览器确认当前简历页的标题、描述、关键词和网页语言正确；未新增非引擎层测试。全量类型检查仍有既有错误，包含语言包索引、通用组件及简历相关类型诊断。

## 配置入口

- 两端统一使用 `src/configs/index.ts` 作为应用配置入口，读取 `config`（应用配置对象）；保留现有配置模块和资源位置。
- 环境读取集中在 `src/configs/env.ts`；实际秘密填写到被忽略的 `.env.local`，`.env.example` 只保留字段说明和空秘密值。
- 本阶段内置模型仍由前端直连，环境中的密钥仍会进入浏览器代码；第三方接口与服务端代理不在本次改动范围。
