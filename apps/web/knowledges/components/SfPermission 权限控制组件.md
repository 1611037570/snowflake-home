# SfPermission 权限控制组件

## 简介

用于控制元素显隐的权限组件。只有当用户拥有指定权限时，该组件包裹的内容才会被渲染。

## 基础用法

```html
<SfPermission permission="sys:user:add">
  <button>添加用户</button>
</SfPermission>
```

## API 参考

### Props (属性)

| 属性名     | 类型     | 默认值 | 说明                         |
| ---------- | -------- | ------ | ---------------------------- |
| permission | `String` | `''`   | 权限标识符，用于校验用户权限 |

### Slots (插槽)

| 插槽名  | 说明                                 | 作用域参数 |
| ------- | ------------------------------------ | ---------- |
| default | 默认插槽，只有权限校验通过时才会渲染 | -          |
