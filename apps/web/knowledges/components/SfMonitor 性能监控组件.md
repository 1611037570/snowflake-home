# SfMonitor 性能监控组件

## 简介

实时展示系统性能指标的悬浮面板，包括 FPS、内存使用、FCP、LCP 和 JS 脚本耗时。支持拖拽移动。

## 基础用法

```html
<SfMonitor />
```

## API 参考

### Props (属性)

无

### 功能说明

- **指标监控**：
  - FPS (帧率)
  - Memory (JS堆内存使用情况)
  - FCP (首次内容绘制)
  - LCP (最大内容绘制)
  - JS Load (JS资源加载耗时)
- **阈值告警**：当指标超过推荐阈值时，会自动变色（警告/错误色）提示。
- **可拖拽**：通过 `useDraggable` 实现面板拖拽。
