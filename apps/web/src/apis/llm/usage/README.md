# 个人 AI 使用情况

- `storage.ts`：三个角色的累计数据存在同一条记录里，键就是角色；读取前清空结构重构前留下的存储。后续接入后端时替换读取与保存两个入口。首页服务次数通过独立的 `getAiServiceOverview` 读取固定展示数据，不读取个人记录、不采集或上报。
- `index.ts`：一次调用的开始、按请求结算与结束落库。成功完成计一次，失败、超时和主动停止计入失败次数；内部工具轮次与重试共用编号，不重复计数。写入整份覆盖并串行化，避免旧快照盖掉新值。
- Web 模型宿主按角色接入统计；直接创建的连接检测模型不接入。固定开场等未请求模型的本地流程不计数。
- `tokens.ts`：归一化服务商返回的输入、输出与总量。每次网络请求只保留一份快照，同一请求的重复事件覆盖而不累加；只返回明细时按输入加输出补算总量，缺失的一律不计。
- 每个角色记录成功次数、失败次数、累计 Token、最近使用时间，并按模型 ID 分别累计次数与 Token。只保存这些数字，不复制提示词、简历、回答、接口地址或密钥。
- 从功能上线后开始累计，不回填旧日志或虚构个人历史。不计算效果评分、采纳率或费用。首页使用固定示例次数，与其他累计指标一起滚动并单独显示加号。
