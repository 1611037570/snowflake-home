# 个人 AI 使用情况

- `storage.ts`：个人调用记录的读取与按编号保存；后续接入后端时替换这两个入口。首页服务次数通过独立的 `getAiServiceOverview` 读取固定展示数据，不读取个人记录、不采集或上报。
- `index.ts`：完整调用的开始、结束、去重、读取合并与失败重试。成功完成一次调用计一次服务，内部工具轮次不重复计数；失败、超时和主动停止只进入近期记录。
- Web 模型宿主按角色接入统计；直接创建的连接检测模型不接入。固定开场等未请求模型的本地流程不计数。
- `tokens.ts`：归一化服务商实际返回的输入、输出、总量与缓存命中用量。每次网络请求保留最新快照，总量与明细事件不重复相加；工具轮次和重试分别累计。缓存命中是输入子集，不另外计入总量；缺失用量显示未提供，部分请求未返回总量时展示已知消耗下限。
- 只保存角色、模型、最终状态、时间与 Token 用量，不复制提示词、简历、回答、接口地址或密钥。失败或停止也保留已返回用量。记录独立保存在 `snowflake-ai-usage`，不受最近十条调试日志及清空日志影响。
- 从功能上线后开始记录，不回填旧日志或虚构个人历史。个人页以模型与总 Token 为主，输入、输出及已提供的缓存用量按需展开；不计算效果评分、采纳率或费用。首页使用固定示例次数，与其他累计指标一起滚动并单独显示加号。
