# 简历共享领域配置

`theme`（主题配置目录）维护用户配置、主题预设、固定能力和公共版式。存储与预览直接使用同一入口，不保留旧路径转发或重复配置快照。

主题外观组件留在 `views/resume/theme/components`。固定声明中的组件编号按实际文件清单校验，不加载组件，也不从组件导出布局能力。

存储保存主题编号和用户覆盖项。运行时展开可编辑参数，固定几何始终从主题声明进入公共布局。

运行 `pnpm --filter @snowflake/web check:resume` 检查领域与存储的依赖边界，并执行公共引擎用例。类型检查继续使用项目的 `type-check` 命令；存在历史诊断时，核对本轮没有新增，不将历史错误声明为通过。

快速验收关闭覆盖率与网页报告生成，避免生成文件触发开发热更新。公共引擎统一检查；浏览器仅选择覆盖不同版式、装饰留白和分片能力的代表主题，无新增改动或失败时不重复全量核验。
