# 独立面试模块

本模块承接工作区的「AI 面试」栏目，编辑器不再展示或启动面试训练。

## 目录职责

- `index.vue`：页面、历史记录与可读记录导出。
- `setupPanel.vue`：先选训练分类，再集中确认岗位、年限与可选资料。
- `interviewRoom.vue`、`outputContent.vue`：逐题作答、语音转写、辅助内容与复盘展示。
- `useInterviewSession.ts`：题数推进、请求中止、暂停恢复、草稿与计时。
- `sessionFlow.ts`：统一派生会话状态、操作权限、下一步动作与真实问答输入；页面和会话操作共用这些判断。
- `storage.ts`：独立面试数据库、写入排队、错误与删除。
- `../shared/resumeSnapshot.ts`：页面数据适配入口，调用简历公共包生成只读业务快照。
- `resumeProfile.ts`：从可选参考简历自动补齐岗位与工作年限。
- `config.ts`、`types.ts`：训练选项、阶段与持久化结构。

## 关键约定

- 正式面试内容通过 `packages/interview-agent` 创建独立智能体，复用 `packages/agent` 的通用组装能力，不依赖简历智能体。五类技能、提示词、工具、完成校验和模型接线均在面试包内维护。参考简历只通过 `packages/resume-core` 的脱敏业务快照输入；有简历时由 `read_interview_resume` 实际读取整份快照，无简历时直接依据岗位、年限与真实作答开展。行业资料从公共包按需读取，不经过简历技能注册表。面试不加载简历写入工具、任务规划或字段补齐规则。
- 简历面试、专项模拟与行测人事面试均先进行两分钟开场自我介绍。固定邀请由面试任务直接提供，不调用模型、不做简历读取或问号校验，开场就绪即开始倒计时并开放作答。支持文字或语音作答及提前提交；暂停时停表，继续或重新打开记录后沿用剩余时间。到时停止输入和语音转写并保留回答，由用户确认提交，空白回答可明确跳过。开场不提供代答辅助，不占正式题数或原技能总分；提交后模型才开始正式出题，不重复邀请自我介绍。自我介绍稿与押题准备模式不启动倒计时。
- 正式出题仍由原技能限制单轮一个考察问题，完成校验拦截多个问号，不因正常的陈述式作答邀请没有问号而中断。生成未完成时区分参考简历读取失败与当前内容未完成，不混为资料校对失败。
- 开始、提交和恢复共用下一步动作决策；已就绪的题目恢复后直接作答，生成中断才重试同一题。正在生成的状态从待办动作对应的输出派生，不额外维护生成开关；进入复盘后禁止再次出题或打开作答辅助。
- 固定开场与未提交任何回答时的结束说明由 `packages/interview-agent/flow.ts` 统一提供，会话直接完成并保存，不进入模型请求或生成状态。空白结束不评分，未提交草稿仍单独保留。
- 简历面试保留八股文与项目深挖，可选择打分并给改进建议或只继续追问，不固定总题数，仅用户主动结束时整体点评。
- 专项模拟保留技术面与业务面，每轮即时评分、依据、优点、待补强点和回答技巧，十轮有效回答后输出完整报告；跳过不计入有效回答，提前结束按原完成度折算规则报告。
- 行测与人事面试固定十道行测加六道 HR：言语理解三题、数量关系三题、判断推理四题交替出题，再覆盖原有六项软技能；评分与提前结束折算沿用原技能。
- 自我介绍保留一百、两百或三百字与简洁、专业、热情风格。面试押题继续提供出题依据、参考答案、回答技巧与准备反馈报告，不强加统一题数。
- 一场训练固定开始时的设置与可选简历快照；不切换编辑器的当前简历，也不随原简历后续修改或删除而改变。
- 姓名、电话、邮箱与微信默认脱敏，用户可在开始前关闭。媒体始终不进入快照。
- 数据保存在独立数据库 `snowflake-interviews` 的 `sessions` 对象仓库中，不进入简历正文、简历会话目录或简历备份。
- 停止生成会实际中止请求，保留部分输出并暂停训练；题目、准备材料与复盘可重新生成，辅助内容中断后允许直接继续作答，需要时再打开辅助生成。关闭仍在生成的辅助窗口也会停止对应请求。切换记录、离开页面与刷新均保留草稿；页面重新打开后训练处于暂停状态。
- 进入复盘后收起作答区，未提交草稿只供查看与导出，不纳入能力评价。
- 初次进入只展示训练分类；点击分类时先检查独立面试官模型，未配置则在当前页面打开共用模型设置，配置完成后继续原分类，不跳转或丢失填写内容。再练一场和正式开始前也复核模型。
- 开始页使用单张紧凑表单，只要求求职岗位与工作年限；目标公司、职位描述和参考简历均为选填，直接展示，不折叠、不展示简历内容、不检查其他简历缺项，也不要求先制作简历。简历列表读取不阻塞无简历起步。
- 选择参考简历只补齐尚未填写的岗位与年限；年限复用简历的参加工作时间与取整口径，已有手动填写内容不覆盖。再练一场复用本场设置和仍存在的参考简历。完整简历资料仅通过脱敏快照提供给模型，不写回原简历。
- `index.vue` 内的面试输入样式覆盖设置、作答与记录搜索，仅在面试模块绘制控件边框与底色，不修改全局表单样式。
- 页面、记录、模型配置与面试内容统一使用 `SfScrollbar`；开始页滚动条使用 `flush`，外层不重复添加内边距，单张表单统一使用 `p-3`。本模块不使用其他内边距数值或响应式放大的内边距。
- 提交、跳过、使用辅助分别记录；提示和参考回答不自动成为候选人答案。复盘只使用已提交问答，未覆盖维度不得虚构评分。
- 仅维护新版独立面试数据，不读取、迁移或兼容旧版面试与混合会话。
- 出题、辅助和复盘均使用独立的“面试官”角色绑定，可以选择已有模型，不继承或回退到小舟、小羊配置；修改面试官绑定不改变简历助手配置。
- 清理浏览器站点数据会删除本地记录，用户可在训练详情导出包含问答、辅助、草稿和复盘的文本记录。
