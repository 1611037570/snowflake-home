# 独立面试模块

本模块承接工作区的「AI 面试」栏目，编辑器不再展示或启动面试训练。

## 目录职责

- `index.vue`：页面、历史记录与可读记录导出。
- `setupPanel.vue`：先选训练分类，再集中确认岗位、年限与可选资料。
- `interviewRoom.vue`、`outputContent.vue`：逐题作答、语音转写、结束复盘与逐题回看。正文统一清除预览默认留白，由根容器或父卡片提供单层内边距。
- `interviewButton.vue`：复用项目按钮，集中维护面试操作的统一尺寸、圆角、边框与底色。
- `interviewModelSettings.vue`：模型与语言偏好设置，配置后承接原分类、重试或回看，不离开当前页面；语言偏好只影响尚未开始的训练。
- `useInterviewSession.ts`：题数推进、原题澄清、请求中止、暂停恢复、草稿与计时。
- `sessionFlow.ts`：一次派生会话状态、回看权限与下一步动作；按题号构造回看输入，出题与复盘使用已提交历史，澄清与回看只携带当前题上下文。
- `storage.ts`：独立面试数据库、写入排队、错误与删除。
- `../shared/resumeSnapshot.ts`：页面数据适配入口，调用简历公共包生成只读业务快照。
- `resumeProfile.ts`：从可选参考简历自动补齐岗位与工作年限。
- `config.ts`、`types.ts`：训练选项、阶段与持久化结构。

## 关键约定

- 正式面试内容通过 `packages/interview-agent` 创建独立智能体，复用 `packages/agent` 的通用组装能力，不依赖简历智能体。五类技能、提示词、工具、完成校验和模型接线均在面试包内维护。参考简历只通过 `packages/resume-core` 的脱敏业务快照输入；有简历时由 `read_interview_resume` 实际读取整份快照，无简历时直接依据岗位、年限与真实作答开展。行业资料从公共包按需读取，不经过简历技能注册表。面试不加载简历写入工具、任务规划或字段补齐规则。
- 面试提示由公共事实与表达、当前动作和本类规则组成；评价规则只用于结束复盘，面试过程不评分、讲评或泄露答案，逐题回看不加载出题或评分规则。请求只传专项训练重点，不携带反馈方式或其他类型的口头稿参数。
- 简历面试、专项模拟与行测人事面试均先进行两分钟开场自我介绍。固定邀请由面试任务直接提供，不调用模型、不做简历读取或问号校验，开场就绪即开始倒计时并开放作答。支持文字或语音作答及提前提交；暂停时停表，继续或重新打开记录后沿用剩余时间。到时停止输入和语音转写并保留回答，由用户确认提交，空白回答可明确跳过。开场不提供代答辅助，不占正式题数或原技能总分；提交后模型才开始正式出题，不重复邀请自我介绍。自我介绍稿与押题准备模式不启动倒计时。
- 面试官的提问、反馈、提示、参考回答与复盘统一简短直白，不复述整段简历或堆砌术语。每轮只问一个具体问题、只考察一个点，不附带子问题或并列要求，其他追问等用户回答后再提。模型结合真实作答选择深入、澄清、难度和情境，不固定项目追问顺序或反馈栏目。专业知识可用于设计明确的假设场景，不能冒充候选人经历；完成校验只核对简历读取与有效正文，不按问号数量重试。生成未完成时区分参考简历读取失败与当前内容未完成。
- 开始、提交和恢复共用下一步动作决策；已就绪题目恢复后直接作答，中断才重试同一题。继续前确认记录保存成功，等待期间切换、暂停或再次继续会使旧操作失效。进入复盘后禁止再次出题或重复结束，报告完成后才开放逐题回看；结束确认只作用于原会话。
- 固定开场与没有实际正式作答时的结束说明由 `packages/interview-agent/flow.ts` 统一提供，会话直接完成并保存，不进入模型请求或生成状态。只有自我介绍或正式题全跳过同样不请求模型评价或评分，未提交草稿仍单独保留。有效回答计数与空样本判断共用同一口径。
- 正式题的“澄清题意”入口解释原题，可使用输入框中的具体疑问；澄清独立保存于原题，不提交正式回答、不推进题数与阶段，不评分或泄露答案。停止、失败或刷新后可直接继续回答原题，不强制重试；没有新疑问时再次澄清会重试未完成说明。应用不靠关键词或模型猜测来修改题数。
- 综合模拟面试结合岗位知识、项目与实际场景，不再选择八股文或项目子方向，不固定总题数；主动结束后统一分析与评分。
- 专项面试只填写一个训练重点，不限于技术或业务二选一；十轮有效回答后统一复盘，跳过与澄清不计入有效回答。复盘分别展示已答表现与完成进度，不按完成比例折算分数。
- 行测与 HR 固定十道行测加六道 HR：言语理解三题、数量关系三题、判断推理四题交替出题，再覆盖六项软技能；过程中不公布正确答案。完整作答按百分制汇总，有跳过或提前结束时只分析已答行测正确率与 HR 表现，进度单独展示，不将未答按零分折算总分。
- 面试押题生成题目、依据、参考回答与准备建议；自我介绍直接生成自然精炼的口头稿，开始页不要求选择字数或风格。这两类不进入模拟作答与计时流程。
- 一场训练固定开始时的设置与可选简历快照；不切换编辑器的当前简历，也不随原简历后续修改或删除而改变。
- 参考简历固定隐藏姓名、电话、邮箱与微信，开始页不增加隐私配置步骤；媒体始终不进入快照。
- 数据保存在独立数据库 `snowflake-interviews` 的 `sessions` 对象仓库中，不进入简历正文、简历会话目录或简历备份。保存失败后仅重试失败记录，写入期间禁用重复重试。
- 停止生成实际中止请求并保留部分内容，题目、准备材料与复盘可重试；回看中止或关闭窗口只停止当前题的生成，面试及原报告保持已完成。切换记录、离开页面与刷新均保留草稿，未结束的训练重新打开后处于暂停状态。
- 进入复盘后收起作答区，未提交草稿只供查看与导出，不纳入能力评价。
- 初次进入只展示训练分类；点击分类时先检查独立面试官模型，未配置则在当前页面打开共用模型设置，配置完成后继续原分类，不跳转或丢失填写内容。再练一场和正式开始前也复核模型。
- 卡片决定用途，进入后只确认单张紧凑资料卡：岗位与年限必填，专项额外填写训练重点；公司、JD 与参考简历选填且直接展示，不折叠、不展示简历正文。语言移至面试设置并复用偏好，不再选择评分、反馈或子方向；点击主按钮直接开始，不另加开始确认。
- 独立自我介绍仅选择简历或填写背景，直接生成可复制口头稿；不要求岗位、年限、公司或 JD，不展示面试进程、不计时、不评分。生成直接提供脱敏资料，不调用资料工具。模拟面试的两分钟开场仍用于候选人真实作答。
- 选择参考简历补齐空白岗位与年限，切换简历时更新上次自动带入的值，保留用户已经改写的内容；年限复用简历的参加工作时间与取整口径。再练一场复用本场设置和仍存在的参考简历。完整简历资料仅通过脱敏快照提供给模型，不写回原简历。
- `index.vue` 内的面试输入样式覆盖设置、作答与记录搜索，仅在面试模块绘制控件边框与底色，不修改全局表单样式。使用普通 CSS 样式块并引用 Tailwind，确保工具类实际编译；记录搜索和分类复用项目表单组件，记录悬停仅反馈整行边框，内部按钮不改变背景。
- 页面、记录、模型配置与面试内容统一使用 `SfScrollbar`；页面外层统一使用 `p-3`，页头与分类标题不再叠加内边距，开始页滚动条使用 `flush`。卡片和表单的内容内边距统一使用 `p-3`，不使用其他内边距数值或响应式放大的内边距。
- 分类按“模拟面试／面试准备”分组，卡片统一图标、说明与底部操作位置；设置页先选可选简历，再填写岗位与年限，选填目标保持展开，按钮旁说明未满足的条件。面试内容区区分当前题、已提交作答和结束后回看；计时、语音转写、暂停、生成、保存和记录筛选均展示真实状态，不增加业务步骤或评分逻辑。流式与完成内容使用相同留白，避免生成结束时正文跳位。
- 聊天使用居中单列对话流，提问靠左、回答靠右，头像与正文对齐；作答区保留文字、语音、题意澄清、跳过与提交，开场计时内嵌，暂停时原位显示恢复。资料、题目导航、面试设置与导出通过“面试信息”按需打开；回到最新沿用编辑器圆形向下图标。按钮固定三十六像素且图标文字同行，不展示常驻本地保存声明，仅提示保存失败。
- 有草稿时跳过先确认，取消后保留原文；生成结束仅在无弹窗且允许作答时聚焦。复盘只评价已提交正式回答，澄清不作能力证据，未提交草稿单独保留；报告完成后，每道已提交正式题提供“答题思路”和“参考回答”，只写入所选题，不改变作答、用时或原报告。思路不读取简历，参考回答按需读取固定快照；两者都不发送其他题的问答。
- 仅维护新版独立面试数据，不读取、迁移或兼容旧版面试与混合会话。
- 出题、澄清、回看和复盘均使用“面试官小羊”的 `xiaoYang`（面试角色）绑定，可以选择已有模型，不继承或回退到“简历助手小舟”配置；不再维护原 `interviewer`（旧面试官角色）绑定，修改小羊绑定不改变简历助手配置。
- 清理浏览器站点数据会删除本地记录，用户可在训练详情导出包含问答、澄清、回看、草稿和复盘的文本记录。
