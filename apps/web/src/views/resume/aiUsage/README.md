# AI 使用情况

顶部是完成次数、累计 Token 合计与三个角色的 Token 分布；下方每个角色一张卡片，展示成功次数、失败次数、累计 Token、最近使用时间与该角色自己的模型分布。两处分布都由同目录的 `usageShareBar.vue` 渲染，该组件只在本页使用并显式引入，不参与全局组件自动注册。

不展示单次调用记录、效果评分或费用，不发起模型调用、不上报；统计口径与存储适配见 [使用统计说明](../../../apis/llm/usage/README.md)。统计里残留的已删除模型由「清除已失效的模型」按钮清理，角色合计同步扣除这些模型的次数与 Token（失败次数不归属模型，保持不变）。

页面保持全宽，使用 `SfScrollbar`，只提供读取失败与保存失败的原地重试。路由与侧栏入口为 `/resume/ai-usage`；简历首页的固定服务次数与个人数据互相独立。带 `?preview` 时展示示例数据用于排查展示，不影响真实记录。
