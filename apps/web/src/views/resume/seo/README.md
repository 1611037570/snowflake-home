# 公开页面静态生成

本目录为首页、模板库、首批十个岗位范本、小舟人工智能、求职指南、求职工具及三个工具详情页、求职统计和通用设置提供可直接阅读的网页正文，不读取用户本地简历、投递记录、模型配置或工具录入值，不改变编辑器运行方式。

## 文件职责

- `catalog.ts`：固定范本地址与既有清单的对应关系。已发布地址保持稳定。
- `content.ts`：构建网页与浏览器共用的正文、链接与文本转义函数，公开内容对用户同样可见。
- `page.ts`：从统一页面配置解析标题、标签、规范地址、收录指令与结构化数据，供构建和客户端共同使用。
- `information.ts`：功能说明与站内链接，指南正文和工具维度直接复用各自的数据文件；构建和实际页面共用内容。
- `publicContent.vue`：首页和模板库中的范本目录，以及详情页正文。
- `exampleDetail.vue`：独立详情页与不存在的范本提示。
- `../../../../scripts/publicPages.ts`：组织静态网页生成与共享正文模块，按页面配置选择是否渲染正文。
- `../../../../scripts/exampleSections.ts`：定位公开范本并提取字面量段落，不执行主题代码，不输出个人联系方式。
- `../../../../scripts/seoHead.ts`：将统一解析结果写成网页头部，替换模板中明确标记的区域。

## 日常维护入口

| 变更 | 维护位置 | 自动同步的结果 |
| --- | --- | --- |
| 修改页面标题、摘要或收录属性 | Web 根目录 `site.config.ts` | 初始网页、客户端导航与站点地图 |
| 新增页面的搜索配置 | `site.config.ts` 中登记路由与双语文案 | 生成独立网页头部；正常业务路由仍在路由文件登记 |
| 发布已有范本为独立页面 | `catalog.ts` 的 `exampleSources`（固定地址与文件名映射） | 详情页、可见目录、站点地图与页面信息 |
| 修改范本正文 | 原有范本源文件 | 构建与浏览器共用的详情段落；开发环境自动更新 |
| 调整通用标签或结构化数据 | `page.ts` | 构建输出和客户端导航同时生效 |
| 调整网页头部输出形式 | `scripts/seoHead.ts` | 默认入口和独立网页同时生效 |

页面配置中的 `content`（静态正文来源）可选目录、范本详情或已登记的功能说明；不声明则仅生成页面信息。`schemaType`（结构化数据类型）决定普通网页、集合页或应用页类型；`parentRoute`（直接上级地址）用于自动生成面包屑；`applicationCategory`（应用用途分类）仅作用于应用类型页面。所有字段的取值与中文说明均在配置类型旁维护。

不要在网页模板、构建插件或客户端另写路由白名单、标题或结构化数据分支。网页模板仅保留统一头部插入位置，客户端只负责将共享结果写入页面。页面上级必须已登记，且不能形成循环。

## 构建与页面接管

沿用 Web 项目的 `pnpm build`，由构建插件在产物中输出各页面的 `index.html`，包括首页、模板库、范本详情、小舟人工智能、求职指南、求职工具和三个工具详情页、求职统计、通用设置。其他已登记路由同时得到独立的标题、描述、规范地址与收录标记。

只有打包时才向仓库根目录的 `dist/web` 写入这些网页；开发服务直接提供应用和共享正文，不写入产物。例如小舟页面输出为 `dist/web/resume/ai/index.html`，求职工具页输出为 `dist/web/resume/tools/index.html`。

静态网页承载公开正文和目录，浏览器加载后仍由现有客户端应用接管；这不是整个编辑器的服务端渲染。首页和模板库在接管后保留相同的岗位范本目录。详情页的“使用这份范本”进入原模板预览流程，由用户确认创建。

共享正文通过 `virtual:resume-public-sections` 提供给浏览器。源文件可放在范本目录任意子目录，文件名须唯一；正文取自默认导出对象的 `data`（公开范本内容），变量名可以调整。只提取字面量，不动态执行函数生成正文；缺失文件、重名文件或空正文会在构建时明确报错。

## 部署约定

仓库根目录 `deploy/nginx-resume.conf` 为轻舟简历域名的服务器配置片段。将其中规则合并到现有站点的 `server` 块，替换冲突的同路径规则；保留现有接口代理、证书与资源缓存配置。不要把片段直接放到另一个产品的域名。

现有部署脚本会复制全部产物，但不会修改或重载服务器配置。服务器配置首次合并后，后续内容更新仍沿用现有构建部署流程。配置缺失时，线上可能仍回退到通用入口，生成独立网页本身不能保证其被返回。

服务器首次接入需要将静态根目录指向部署产物位置、合并本仓库的配置片段并重载站点配置。`/resume/` 下优先查找对应目录的 `index.html`，编辑器保留通用入口回退，未知范本返回不存在状态。以后更新正文只需重新打包和复制产物，无需为每个新页面增加服务器规则，也不需要新增服务端渲染进程。

站点地图自动包含已登记范本。禁止收录通过网页中的 `noindex`（禁止索引指令）声明，不再用抓取禁令阻止搜索引擎读取该指令；该指令不提供访问权限保护。
