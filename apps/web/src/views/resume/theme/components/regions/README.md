# 简历页区域契约

本文档约定简历页的分层结构、区域槽位与几何口径，是区域相关改动的验收依据。
它分为「目标形态」与「落地状态」两部分：目标形态是最终要迭代到的结构，落地状态记录当前代码实际到哪一步。

## 目标形态：四层

```text
Page      纸张      宽高、背景、边框、圆角、页尾
 └ Region  通栏层    槽位 + padding（唯一几何声明）+ 外观组件（自绘）
    └ Column  栏     栏宽、栏间距
       └ Module      模块内容
```

| 层     | 只管                                          | 不管       |
| ------ | --------------------------------------------- | ---------- |
| Page   | 纸张尺寸、背景、边框、圆角、页码              | 内容留白   |
| Region | 槽位、`padding`（进引擎）、外观自绘（进组件） | 内容怎么排 |
| Column | 栏宽、栏间距                                  | 背景与留白 |
| Module | 内容本身、模块内负 margin 跨界                | 页面级留白 |

## 区域槽位

槽位定义见 `theme/regionSlots.ts`，页面从上到下固定三个：

| 槽位     | 形态                     | 高度来源                   | 是否装箱   |
| -------- | ------------------------ | -------------------------- | ---------- |
| `slogan` | 只首页，内容为空则不渲染 | 实测一次（内容 + padding） | 否         |
| `user`   | 只首页                   | 实测一次（内容 + padding） | 否         |
| `main`   | 跨页                     | 接管剩余高度               | 是（唯一） |

## 几何口径

目标形态是两阶段：

```text
第一阶段：只量高度，不装箱
  sloganBox = slogan 内容高 + slogan.padding 上下
  userBox   = user 内容高   + user.padding 上下

第二阶段：只给 main 装箱
  首页 main 可用高   = 页面高 − page.border − 页尾 − sloganBox − userBox − main.padding 上下
  后续页 main 可用高 = 页面高 − page.border − 页尾 − main.padding 上下
  main 栏宽          = 页面内宽 − main.padding 左右 − 栏间距
```

## 区域外观组件

外观编号由 `ui.theme.region[槽位]` 指定，注册表做静态映射（不使用异步组件，保证测量时几何立即就绪）。

| 编号    | 用途                                                                 |
| ------- | -------------------------------------------------------------------- |
| `plain` | 不绘制任何底色与留白，slogan / user 的缺省外观                       |
| `view`  | 正文容器外观，main 的缺省外观，读取 `viewStyle` 的背景、圆角与内边距 |

外观组件自绘颜色、形状、装饰与层序；绘制层必须是绝对定位且不影响内容盒尺寸。

## 不变量

1. **几何只在区域 `padding`**：外观组件不得自造布局留白（用 `padding`/`margin` 改内容位置），要内缩就改声明。
2. **测量与渲染同源**：同一个区域组件被预览层与测量树共用，一次定义两处消费。
3. **首屏可用高度公式只有一份**：分页与「一页纸」共用，避免压缩时错位。
4. **头部区域不做页首口径扣除**：slogan / user 不出现在第二页、不被切分，测得多少就是多少；`droppedTopSpacing` / `leadingMargin` 那套只作用于 main。
5. **空内容零高度**：slogan 数据为空时整区域（含 padding）高度为 0 且不渲染。
6. **绘制不参与布局**：组件内的绝对定位层可任意形状。
7. **导出三路径一致**：长图 PNG / 长图 PDF 走测量树，分页 PDF / 浏览器打印走真实页克隆；分页 PDF 会把克隆的圆角清零，`page.radius` 上线时要一并评估。
8. **放不下的兜底**：slogan / user 超过整页高度时不能静默丢内容，开发期报警且溢出可见。

## 落地状态

| 能力                                                | 状态                                                      |
| --------------------------------------------------- | --------------------------------------------------------- |
| 区域槽位常量与类型（`theme/regionSlots.ts`）        | 已落地                                                    |
| 区域分发器与缺省外观（`theme/components/regions/`） | 已落地，行为与旧版裸元素一致                              |
| 顶部标语模块（数据、表单、适配器、内容组件）        | 已落地，无标语数据时不生成节点与区域                      |
| 顶部标语独占最前通栏区域                            | 已落地，标语区域只在存在标语模块时创建                    |
| 区域 `padding` 声明（引擎与外观同源读取）           | 已落地：标语与个人信息区域读主题声明，main 暂读 viewStyle |
| slogan 槽位外观组件                                 | 已落地：`themes/banner.vue` 通栏色带                      |
| `page.border / radius` 进入几何                     | 未落地                                                    |
| 两阶段几何（slogan / user 先量、main 接管剩余）     | 未落地，当前由区域高度结算顺带实现，尚未收敛为固定两阶段  |

未落地的能力一律沿用现有口径：页面留白仍由 `ui.page.padding` 承担，正文容器内边距仍由 `viewStyle.padding` 折算成 main 区域的 `padding`。

区域留白由 `theme/regionPadding.ts` 的 `resolveRegionPadding` 统一解析：引擎用它扣除栏宽与可用高度，区域外观组件用同一份结果决定自身内边距，两侧不得各写一份默认值。

引擎下发的区域编号是 `slogan` / `header` / `main`，到槽位的映射写在 `theme/regionSlots.ts` 的 `regionSlotByRegionId`；引擎改为直接下发槽位编号后该映射退化成恒等映射并被删除。
