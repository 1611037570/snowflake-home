# resume assistant 目录说明

本目录只负责简历助手的路由、流程和会话展示，不保存 AI 请求、技能正文、字段契约或工具实现。

```text
editor/panel/index.vue（异步挂载助手）
  → chat/index.vue（会话与引导宿主）
       → flows（简历建议卡片与交互流程）
       → routing/registry（登记按需 AI 能力）
       → useResumeAssistant（装配本轮工具与简历上下文）
       → chat/useChatRequest（维护会话展示、取消与撤回）
            → packages/resume-agent（统一会话内建立任务契约、装配工具、执行 ReAct 并核对完成证据）
```

目录职责：

- `chat/`：维护会话消息、输入、生成状态、撤回入口和展示组件；写入状态直接消费运行时结构化证据。
- `flows.ts`：维护助手功能入口、引导步骤和请求上下文。
- 面试训练、语音作答、辅助回答与面试记录由工作区独立的 `../interview/` 维护，不再混入简历助手。
- 一键优化由 `../components/aiOptimize/` 承接，一次生成完整简历草稿与 JSON 报告，默认只展示报告；主动查看简历或对比后才隐藏报告并渲染简历，对比时同时展示优化前后，可返回报告，由用户选择保存或放弃，不创建聊天消息；助手入口只投递 `resume-open-optimize` 事件，非编辑器页面由布局转到 `/resume/optimize` 内嵌展开，一键调整继续保留助手流程。
- `context/`：适配 Store 与简历 Agent，在请求周期内冻结模块选择、脱敏和读取范围；字段契约生成与注册位于 `../shared/`，由简历公共包保存。
- `routing/registry.ts`：登记常驻提示，并复用简历智能体包提供的轻量任务能力与参考知识目录。
- `routing/defaultPrompt.ts`：装配助手身份、事实边界与默认输出提示；通用操作规则由简历 Agent 运行时维护。
- `useResumeAssistant.ts`：根据当前简历状态装配 Web 数据上下文、简历 Agent 工具与错误引导。
- `changes/`：捕获本地写入前后快照、提取富文本的可读内容并计算文字差异；只服务于改动查看，不参与模型决策。

依赖约定：

- 助手可以调用 `packages/resume-agent`，`packages/resume-agent` 不得依赖助手。
- 简历专属技能、提示词、请求任务、工具与报告解析写入 `packages/resume-agent`；字段、富文本、脱敏和媒体等公共数据能力写入 `packages/resume-core`。
- 对话功能入口、引导步骤、技能选择关系或会话交互写入本目录；独立优化的入口与状态在共用优化模块维护。
- 页面不得直接创建模型请求，统一调用 `@snowflake/resume-agent` 的公开出口。
- 应用启动时分别注册公共数据契约和两个业务智能体；简历 Agent 只接收自己的模型、文案和业务工具，不反向读取 Web 实现或面试智能体。

改动查看约定：

- 写入执行器通过可选通知逐条捕获真实变化，原有执行顺序、结果与 AI 工具协议保持原样；同值、失败和复用的工具结果不重复产生详情。
- 每条助手回复单独保存本轮新增、修改、删除、排序及展示语言变化；详情仅存当前会话内存，不进入消息持久化、模型上下文或日志，切换简历与刷新后不保留。
- `chat/changeList.vue` 复用统一清单和对比弹窗；正文差异打开弹窗时计算，富文本仅提取可读文字，纯格式变化单独说明；长正文限制差异计算量，不将标记写回简历。
- 停止或报错仍显示已经写入成功的改动，撤回成功后清除对应详情；记录或展示异常只提示详情不可用，不阻断写入。
- 第一版逐项展示，不自动合并记录、不提供单条撤回与预览定位；字段快捷润色未走助手写入通知，不纳入此清单。

本轮变更：助手实际写入结果接入改动清单与红绿对比弹窗，移除固定演示；按执行规范未运行构建、测试或浏览器验证。
